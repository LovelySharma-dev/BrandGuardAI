# PDF Preparation and Organiser Form Checklist

## Before exporting the PDF

- [ ] Obtain and read official organiser instructions (not available in this repository at review time)
- [ ] Replace all placeholders: `[TEAM_NAME]`, `[TEAM_SIZE]`, participant legal names, emails, roles
- [ ] Confirm the official track/challenge title and every required field against the organiser packet
- [ ] Confirm final product name or retain the provisional-name note
- [ ] Remove any fabricated metrics, interviews, or customer logos
- [ ] Check whether the organiser requires the 11 topics mapped below; this mapping is a working draft, not independently verified official requirements
- [ ] Add an architecture diagram only if required or useful; no diagram is currently included in the submission draft
- [ ] Spell-check; follow the official page, format, and file-size limits (**Unresolved** until the packet is supplied)

## Export steps (use existing tools only)

1. Open `submission-draft.md` in an already available document editor that can export PDF; do not install a converter just for this draft.
2. Apply organiser formatting only after the official packet is available.
3. Export to PDF using that editor's built-in export or print-to-PDF function.
4. Open the PDF and check page breaks, tables, links, and every remaining placeholder.
5. Upload only after all official requirements and required fields are confirmed.
6. Save the actual confirmation email/screenshot in the organiser's designated location, if required.

## After submit

- [ ] Record the actual submission timestamp and confirmation ID: `[SUBMISSION_CONFIRMATION_ID]`
- [ ] Share PDF + confirmation with all teammates
- [ ] Freeze Round 1 docs; only correct factual errors
- [ ] Keep any build-window statement consistent with organiser permission and dated evidence

## Judging criteria quick pass (self review)

- [ ] Problem framing makes no unsupported competitor or uniqueness claims
- [ ] Solution emphasises evidence gate + human approvals
- [ ] Tech plan names trade-offs (esp. vectors optional)
- [ ] Originality called out as mechanism, not name
- [ ] Scope lists exclusions
